# create empty risk column
air_quality$risk <- NA

# variables to track unhealthy streaks
current_unhealthy_streak <- 0
max_unhealthy_streak <- 0

# for loop to classify risk levels
for(i in 1:nrow(air_quality))
  {
  if(air_quality$pm25[i] < 12)  # good air quality
    { air_quality$risk[i] <- "good"
      current_unhealthy_streak <- 0}
  
  else if(air_quality$pm25[i] >= 12 & air_quality$pm25[i] <= 35.4)  # moderate air quality 
    { air_quality$risk[i] <- "moderate"
      current_unhealthy_streak <- 0}
  
  else {air_quality$risk[i] <- "unhealthy" # unhealthy air quality 
  
  if(air_quality$risk[i] == "unhealthy")
  {current_unhealthy_streak <- current_unhealthy_streak + 1
  
  if(current_unhealthy_streak > max_unhealthy_streak)
  {max_unhealthy_streak <- current_unhealthy_streak}}
  
  else
  {current_unhealthy_streak <- 0}}
}

Interpretation of PM2.5 Monitoring Results

The simulated air quality data showed seasonal differences in PM2.5 and unhealthy air quality events throughout the year. Summer experienced the highest number of unhealthy days with 10 total days classified as unhealthy. Winter had the fewest unhealthy days at 6. Spring and fall showed moderate levels of unhealthy air quality with 7 and 8 days. The maximum consecutive streak of unhealthy air was only 2. Overall PM2.5 concentration had and average value of 18.38 ug/m3, with some extreme pollution events reaching a max of 56.89 ug/m3. These findings suggest that while most days experienced moderate air quality conditions, occasional shirt term pollution spikes could still pose risks to public health.
